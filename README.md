# Dracoria Evolved 🐉

A portrait-oriented HD-2D fantasy RPG prototype for **Codea Modern (Lua)** on iPhone.

## Current milestone: Build 015
- A shared character data model across creator and exploration
- Eight-direction movement
- Four customization options in each of eight categories
- A placeholder pixel renderer until production-quality transparent sprite sheets are ready
- A clean repository foundation for layered sprite atlases

## Getting started
1. Open `Codea/Main.lua` in this repository.
2. Copy it into the Main tab of a new Codea project on your iPhone.
3. Run the project. Customize your hero, press ENTER WORLD, then walk and press EDIT to customize again.

**Important:** GitHub changes do not automatically appear in Codea. A safe download/import workflow is a future milestone.

## Art pipeline
See `docs/SPRITES.md`. The artwork must be real transparent PNG sprite sheets with precisely aligned frames. Concept images are not production atlases.
